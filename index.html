Features

Everything at a glance

No browser tabs, no context switching. Your CI status lives where you already look.

Live polling

Configurable polling interval from 30 seconds to 1 hour. Always up to date, never noisy.

Failure notifications

Desktop alerts fire only on state transitions to failure. No alert fatigue, just the signal you need.

Floating window

Optional always-on-top panel shows your PR status while you work. Toggle it on or off anytime.

Grouped by org

PRs organized by organization and user, sorted by most recent. Find what you need fast.

Deep links

Click any job to jump straight to the GitHub check-run page. Drill into failures instantly.

Secure storage

Your GitHub token is stored in the macOS Keychain. Never written to disk in plain text.

At a glance

Four states, zero ambiguity

The menu bar icon changes color to reflect your overall CI status.

All passing

Every check on every PR succeeded

Failure

One or more checks have failed

In progress

Checks are currently running

No PRs

No open pull requests found

Get started

Up and running in 3 steps

1

Get the app

Download the latest release from GitHub Releases, or build from source.

git clone https://github.com/erickgnavar/kanshi && cd kanshi && just release
2

Move to Applications

Drag Kanshi.app to your Applications folder. Because the app is not notarized, remove the quarantine flag:

xattr -dr com.apple.quarantine /Applications/Kanshi.app
3

Add your GitHub token

Click the menu bar icon, expand Settings, and paste your Personal Access Token with repo scope.
